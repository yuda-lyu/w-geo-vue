WSptLiqAnalysis

提供SPT液化分析之整合組件，含分析方法勾選區、分析結果數據表格(WTableEdit)，以及分析結果之深度剖線繪圖區(WSptLiqPlotDepthsWithGradesAndTools)

內部先依kpTransRowKey轉換rows各欄位key，再以w-geo之calcLiquefaction計算液化分析，並由計算結果產生表格設定與各參數繪圖狀態物件。地下水位取自rows第1筆之waterLevel、waterLevelUsual、waterLevelDesign(依序覆蓋)

表格為唯讀不提供編輯，計算結果中key含'-err'與'-stateFS'者會自動轉換角括號為HTML實體字元並開啟儲存格提示框

表格之欄名(依kpHead顯示上下標)、儲存格(依kpDig取位)與提示框皆經WTableEdit之slot(head-render、cell-render、cell-tooltip)實作，不再使用w-aggrid-vue 2.0.56起已移除之kpHeadRender、kpCellRender、kpCellTooltip設定

計算結果中來源為文字之數值欄會於顯示文字不變之前提下轉為數值並使用數值過濾器，其餘有值之欄使用文字過濾器；數值過濾比對原值而非依kpDig取位後之顯示值(例如顯示15.275之原值15.274999999999999以15.275過濾不中)

儲存格值以HTML解析呈現(同既有語意)，rows不得含未經處理之不可信文字；'-err'與'-stateFS'欄之值為HTML實體字串，匯出值與rows插槽亦為實體字串，文字過濾須以實體字串比對

分析(含w-geo計算)拋出例外時，不顯示表格與繪圖並於組件內顯示錯誤訊息，同時發出error事件；輸入rows為空時視為尚無數據，不計算亦不視為錯誤

繪圖參數之勾選：首次分析結果與日後新勾選之液化分析方法，其符合keyParamSelects之參數(-FS、-cmpFS、-PL、-stlTS、-stlIY等)自動勾選並繪圖；取消勾選方法時其參數與圖移除，再次勾選時重新自動勾選；已存在參數之勾選結果維持使用者之選擇，不因分析結果更新而改變

具名插槽(slot)：'zone-top'為繪圖區上方之資訊區塊，提供作用域參數row0(分析結果第1筆)、rown(分析結果最末筆)、rows(分析結果全部)

rows Array [] No 輸入各深度之土層與試驗數據物件陣列，預設[]
kpTransRowKey Object - No 輸入rows各欄位key之轉換對照物件，key為輸入資料欄位key，值為分析用欄位key，預設已提供SPTN、Gt_dry、Gt_sat、ctFine、code、USCS等對照
kpHead Object - No 輸入分析用欄位key對應表格標題與繪圖軸標題之物件，值可使用底線與上下標語法，並可使用'{unitSvSvp}'標記代表應力單位，預設已提供PGA、depth、waterLevel、WC、PI、FC、γ、σ等對照
kpDig Object - No 輸入分析用欄位key對應表格數值取用小數點位數之物件，預設已提供depth、N60、WC、γ、σ、D10等對照
keyParamSelects Array - No 輸入預設勾選繪圖參數之過濾設定物件陣列，套用於首次出現與日後新出現之參數(例如新勾選液化分析方法後其-FS、-PL、-stlTS、-stlIY等)，已出現參數之勾選結果不因此改變，物件可給予keyFull(需完全相同)或keyPart(需部份含有)，預設已提供Geolayer、N60、FC(%)、-FS、-cmpFS、-PL、-stl等過濾
depthTitle String 'Depth(m)' No 輸入繪圖深度軸標題字串，預設'Depth(m)'
optionsPic Object {} No 輸入繪圖設定物件，鍵值同WSptLiqPlotDepthsWithGradesAndTools之optionsPic並向下傳遞，預設{}
optionsTable Object {} No 輸入提供組件WTableEdit之額外參數物件，預設{}
optionsToolPlot Object {} No 輸入提供組件WSptLiqPlotDepthsWithGradesAndTools之額外參數物件，預設{}
optionsMethodData Object {} No 輸入標題文字設定物件，預設{}
optionsMethodData.textMethods String 'Methods' No 輸入分析方法勾選區標題字串，預設'Methods'
optionsMethodData.textTable String 'Table data' No 輸入數據表格區標題字串，預設'Table data'
