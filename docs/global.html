cvNumCols(rows, kpDigopt) → {Object}

Description:

  • 將表格各列中以文字傳入之數值欄轉為數值，並依欄位型別給予過濾器型別

    計算結果列之數值欄在來源列為文字時會原樣保留文字，表格預設之數值過濾器('num')比對文字值會得不到列。 逐欄判型：①欄內非空值皆為數值或數值字串，且各值轉為數值前後之顯示文字(含kpDig取位)皆相同時，該欄文字值轉為數值並給予'num'過濾器； ②其餘有非空值之欄維持原值並給予'text'過濾器(例如含NP、-之欄，或不取位而尾零會因轉數值消失之欄)；③全為空值之欄不指定(沿用表格預設之數值過濾器，因無資料故無實質影響)。 顯示文字不變為硬約束，故轉換不會改變儲存格所見：有kpDig之欄因取位函數內部即先轉數值，轉換前後之顯示文字必然相同(檢查恆成立，保障來自取位本身)， 無kpDig之欄才實際比對字面(尾零、前導零、前後空白、科學記號、正負號、十六進位字樣等字面不同者維持文字)； 數值字串另須為有限值且絕對值不超過安全整數上限，否則(Infinity、1e309、超過2^53之整數)維持文字，避免轉換時夾限或失去精度

getCellText(v, idigopt) → {String}

Description:

  • 取得表格儲存格之顯示文字

    給予idig(kpDig內該欄位之小數位數)且值為數字(含數字字串)時取位，其餘空值為空字串、字串與數字原樣轉字串、物件與陣列轉JSON字串(含循環參照時為空字串)， 轉換規則同w-aggrid-vue預設儲存格顯示，使儲存格slot與數值欄轉型前後之顯示比對共用同一份定義
