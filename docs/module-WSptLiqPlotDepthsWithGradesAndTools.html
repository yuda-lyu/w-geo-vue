WSptLiqPlotDepthsWithGradesAndTools

於WSptLiqPlotDepthsWithGrades外，另提供參數勾選區與工具區之繪圖組件，可由使用者自行勾選欲繪製參數、切換土柱合併重複與鑽孔潛勢資訊、切換是否繪製折線、調整土柱圖寬與數據圖寬高，並可將繪圖區下載成為圖片

參數勾選區依groupParams分組並過濾sts產生，各參數僅會歸屬於最先匹配之群組。勾選結果會同步觸發update:keyStsSelects事件，故可由外部使用keyStsSelects.sync雙向綁定

具名插槽(slot)：'zone-top'為繪圖區上方之資訊區塊，需開啟鑽孔與潛勢資訊才會顯示

Props

Name Type Default value Required? Description
sts Array [] No 輸入多個繪圖狀態物件陣列，可由getSts產生，格式同WSptLiqPlotDepths之sts，預設[]
keyStsSelects Array [] No 輸入欲繪製參數之key字串陣列，可使用.sync雙向綁定，預設[]
optionsPic Object {} No 輸入繪圖設定物件，鍵值同WSptLiqPlotDepthsWithGrades之optionsPic並向下傳遞，其中geocolMergeSameLayers由工具區之土柱合併重複開關複寫，預設{}

textPlots String 'Plots' No 輸入繪圖區標題字串，預設'Plots'

textGeocolPlotWidth String 'Layers plot width(px)' No 輸入土柱圖寬滑桿文字字串，預設'Layers plot width(px)'
textPlotWidth String 'Plot width(px)' No 輸入數據圖寬滑桿文字字串，預設'Plot width(px)'

groupParams.flts.keyFull String - No 輸入需完全相同之參數key字串，預設無
groupParams.flts.keyPart String - No 輸入需部份含有之參數key字串，與keyFull擇一給予且優先使用，預設無
groupParams.flts.text String - No 輸入參數顯示文字字串，給予'{key}'代表直接顯示參數key，預設無

Data

Name Type Default value Description
plotWithLine Boolean - 儲存是否繪製折線布林值，關閉時各參數圖改以散點繪製
plotWidth Number - 儲存數據圖寬度數字，單位px
plotHeight Number - 儲存數據圖高度數字，單位px
plotWithGrade Boolean - 儲存是否顯示鑽孔與潛勢資訊(含分級評估與zone-top插槽)布林值
geocolPlotWidth Number - 儲存土柱圖寬度數字，單位px
geocolMergeSameLayers Boolean - 儲存土柱圖是否合併相鄰重複土層布林值
downloadPicProcessing Boolean - 儲存是否正在下載圖片布林值
piss Array - 儲存參數勾選區之各分組與其參數項目陣列
keyStsSelectsTrans Array - 儲存內部使用之已勾選參數key字串陣列
kpPis Object - 儲存參數key對應是否勾選物件

Computed

Name Type Description
useSts Array 回傳實際供繪圖使用之繪圖狀態物件陣列，已過濾未勾選參數並套用圖寬圖高與繪圖型態
useOptionsExt Object 回傳實際向下傳遞至WSptLiqPlotDepthsWithGrades之繪圖設定物件
useTextDownloadPic String 回傳下載圖片按鈕之顯示文字字串
