WSptLiqPlotDepths

並排繪製多個參數之深度剖線圖，當sts第1筆之key為'Geolayer'時，會於最左側改以土柱圖繪製地層並標註地下水位，其餘參數則各自呼叫WSptLiqPlotDepth繪圖，且僅最左側參數圖保留深度軸標題與刻度文字

具名插槽(slot)：'zone-top-geolayer'與'zone-bottom-geolayer'為土柱圖之上下方區塊，提供作用域參數width與height；'zone-top-pic'與'zone-bottom-pic'為各參數圖之上下方區塊，提供作用域參數width、height與st，各區塊高度由optionsPic之zoneTopHeight與zoneBottomHeight控制

土柱圖示需由網路載入w-demores之dataCivilSoilCodeIcon，未載入完成前不繪製土柱圖

Props

Name Type Default value Required? Description
sts Array [] No 輸入多個繪圖狀態物件陣列，可由getSts產生，各物件格式同WSptLiqPlotDepth之st，其中key為'Geolayer'者代表土柱圖，預設[]
optionsPic Object {} No 輸入繪圖設定物件，除下列鍵值外，其餘鍵值同WSptLiqPlotDepth之optionsPic並向下傳遞，預設{}
optionsPic.zoneTopHeight Number 0 No 輸入繪圖上方插槽區塊高度數字，單位px，預設0
optionsPic.zoneBottomHeight Number 0 No 輸入繪圖下方插槽區塊高度數字，單位px，預設0
optionsPic.spaceGeolayer Number 10 No 輸入土柱圖與參數圖之間距數字，單位px，預設10
optionsPic.spacePlot Number 0 No 輸入各參數圖之間距數字，單位px，預設0
optionsPic.geocolKeyValueStart String 'depthStart' No 輸入土柱圖各層起始深度之欄位key字串，預設'depthStart'
optionsPic.geocolKeyValueEnd String 'depthEnd' No 輸入土柱圖各層結束深度之欄位key字串，預設'depthEnd'
optionsPic.geocolKeyText String 'description' No 輸入土柱圖各層說明文字之欄位key字串，預設'description'
optionsPic.geocolKeyLegendCode String 'legendCode' No 輸入土柱圖各層土壤圖例代碼之欄位key字串，供對應土壤圖示，預設'legendCode'
optionsPic.geocolMergeSameLayers Boolean false No 輸入土柱圖是否合併相鄰且圖例代碼與說明文字皆相同土層布林值，預設false

kpGlIcon Object - 儲存土壤圖例代碼對應土壤圖示物件
